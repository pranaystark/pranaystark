# Pranay Stark

Ubuntu GNOME is the daily driver. Mac when a job forces it. ESP32s for anything that should be obvious from across the room.

I got tired of discovering Antigravity and SuperGrok were empty *after* the reply died, so the panel now carries remaining quota. Two chips. Fetch on login and when I click — nothing polls in the background.

![GNOME tray: Grok remaining and AGY remaining](gnome-panel.png)

Same pattern as the rest of the desk:

- **[ai-limits](https://github.com/pranaystark/ai-limits)** — Python / GTK 4 / AppIndicator. GNOME 50, Wayland. The screenshot above.
- **[primaryclip](https://github.com/pranaystark/primaryclip)** — KDE select-to-copy + middle-click paste on macOS. Leaves ⌘C alone.
- **[esp-uptime](https://github.com/pranaystark/esp-uptime)** — ESP32-S3, seven WS2812Bs. Green = homelab up. Red blink = walk over.
- **[esp-infrastructure_monitor](https://github.com/pranaystark/esp-infrastructure_monitor)** — same job on a XIAO ESP32-C6, WiFiManager so it isn’t hard-coded to one SSID.
- **[SONOFF_MQTT](https://github.com/pranaystark/SONOFF_MQTT)** / **[Ifttt-button](https://github.com/pranaystark/Ifttt-button)** — older house wiring. Sonoff temp/humidity over Adafruit MQTT; ESP8266-01 as a dash-style button.
